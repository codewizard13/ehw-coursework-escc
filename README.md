## Overview 🎯

A **Computer Programmer** with an **Associate of Applied Science (A.A.S.)** degree has a deeper understanding of software development, coding, and systems design. This degree equips students with practical, career-oriented skills to build, test, and maintain applications and software systems, preparing them for a variety of roles in the tech industry.

The A.A.S. in Computer Programming emphasizes hands-on experience and technical expertise, with graduates ready to enter the workforce in intermediate-level programming and software development positions.

---

## Career Focus 💼

Computer Programmers in this program develop skills for the following primary work tasks:

1. **Software Development** – Designing, coding, and debugging applications in various programming languages
2. **Systems Analysis** – Understanding client needs to develop software solutions
3. **Testing & Debugging** – Performing extensive testing to ensure functionality, security, and performance
4. **Database Management** – Creating and managing databases using SQL and related tools
5. **Team Collaboration** – Working with engineers, developers, project managers, and stakeholders
6. **Version Control & Documentation** – Managing code versions with Git and creating technical documentation

## Getting Started 🚀

### Prerequisites
- High school diploma or GED
- Basic computer literacy
- Algebra or prerequisite math skills (depends on program entry requirements)

### How to Use These Notes
- **Location:** Notes are organized in [courses/](/courses/) by semester and course code
- **Organization:** Structured by course, chapter/unit, assignments, and projects
- **Progress:** Track completed assignments, projects, and grade progress

### Study Tips
- Review course prerequisites before starting each semester
- Collaborate with classmates on group projects
- Attend office hours for clarification on complex topics
- Practice coding daily—this is a skill-based program
- Maintain organized version control repositories for all code projects
