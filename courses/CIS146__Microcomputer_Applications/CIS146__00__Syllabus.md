# 📘 Course Syllabus: CIS 146 — Microcomputer Applications

## Course Overview

This course introduces common microcomputer productivity applications and digital workflow tools used in academic and business settings. Students learn how to use software for document creation, spreadsheets, presentation design, and practical digital communication.

**Real-world application:** microcomputer applications are used in offices, education, business process support, reporting, and everyday productivity across many careers.

### Learning Outcomes

- Use core productivity software to complete practical tasks.
- Create and format documents, spreadsheets, and presentations.
- Organize files and data for effective workplace productivity.
- Understand software basics required in a professional environment.
- Apply digital tools to real-world tasks and reports.

### Topics Covered

- Word processing and document formatting
- Spreadsheet functions and data organization
- Charts, formulas, and analysis basics
- Presentation development and design
- File management and digital productivity tools
- Basic productivity workflows in business environments

### Assessment

- Software practice exercises
- Projects and assignments
- Quizzes or practical evaluations
- Final productivity application tasks

### Materials

- Computer workstation and software suite
- Course exercises and examples
- Templates and project instructions
- Notes and reference guides
