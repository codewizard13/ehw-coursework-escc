# 📘 Course Syllabus: CIS 202 — Python Programming

## Course Overview

This course introduces Python, one of the most widely used programming languages for automation, scripting, data work, and software development. Students learn Python syntax, logic, data handling, and practical programming techniques used in both academic and professional settings.

**Real-world application:** Python is used in automation, data analysis, web development, AI tools, scientific computing, and software testing.

### Learning Outcomes

- Write Python programs using variables, data types, and control structures.
- Use functions and modules to organize code effectively.
- Work with lists, dictionaries, and common data structures.
- Apply debugging and testing techniques to improve code reliability.
- Solve practical problems using Python in real-world scenarios.

### Topics Covered

- Python syntax and program structure
- Input, output, variables, and data types
- Decision structures and loops
- Functions and scope
- Lists, dictionaries, and sets
- File handling and data processing
- Error handling and debugging
- Basic automation and scripting tasks

### Assessment

- Programming exercises
- Lab tasks and projects
- Quizzes and practical checks
- Final coding activity or project

### Materials

- Python interpreter and editor
- VS Code or equivalent environment
- Course notes and coding exercises
- Sample scripts and project prompts
