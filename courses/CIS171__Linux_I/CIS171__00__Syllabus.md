# 📘 Course Syllabus: CIS 171 — Linux I

## Course Overview

This course introduces the fundamentals of the Linux operating system, command line interface, and system workflows used in modern computing. Students learn how to navigate directories, manage files, use shell tools, and understand permissions, processes, and scripting in a practical computing environment.

**Real-world application:** Linux is foundational for servers, cloud infrastructure, cybersecurity, automation, software engineering, and many developer workflows.

### Learning Outcomes

By the end of this course, students should be able to:

- Use the Linux command line to navigate and manage files and folders.
- Explain file permissions, ownership, and basic system security concepts.
- Work with processes, pipes, redirection, and shell utilities.
- Troubleshoot command-line errors and apply practical problem-solving techniques.
- Apply Linux skills in scripting, administration, and developer environments.

### Topics Covered

- Introduction to Linux and operating systems
- Terminal navigation and shell basics
- Files, directories, and paths
- Permissions, ownership, and access control
- Text processing and filtering tools
- Redirection, pipes, and command chaining
- Processes and system monitoring
- Scripting basics and automation
- Basic networking and remote access concepts

### Assessment

- Lab exercises and command practice
- Quizzes and short checks
- Practical projects
- Final verification activity or exam

### Materials

- Linux terminal or Ubuntu environment
- Git and VS Code
- Command-line reference notes
- Course handouts and labs
