In this assignment, please address the following topic:

*   Explain the role of essential network security protocols (such as HTTPS, SSH, and IPSec) in safeguarding data transmission. Illustrate your explanation with examples of how these protocols defend against common network threats.

### **Assignment Submission Requirements:**  

*   Answer the prompt for the assignment in one page or less, excluding the title and reference pages. 
*   The title page should include the following:   
    *   Full name of the student
    *   Week # Reading Assignment #
    *   Course name and code
    *   Instructor’s name
*   There should be a minimum of two credible references, and these should be cited as per APA Style. 
*   Papers should be saved in the following naming format prior to submission:
    *   COURSE NUMBER\_Section #\_Student Name\_Week # Reading Assignment #
    *   **Example:** CIS 001\_Section 1\_Jane Doe\_Week 1 Reading Assignment 1
