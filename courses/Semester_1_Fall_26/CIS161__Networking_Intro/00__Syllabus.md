## Course Description

This course provides students with an introduction to networking fundamentals. Topics include network terminology and protocols, local area networks (LANs), wide area networks (WANs), Open System Interconnection (OSI) model, network topologies, IP addressing, and networking hardware and software.

## Learning Outcomes

By the end of this course, students will be able to:

1. Identify networking terminology, protocols, and standards.
2. Explain the OSI and TCP/IP models.
3. Configure and troubleshoot IP addressing.
4. Describe networking hardware, software, and topologies.
5. Recognize LAN and WAN technologies and applications.

## Certification Path

The certification path includes:

- **Cisco Basic Network Badge:** The first step in demonstrating foundational networking skills.
- **Fiber Optics Badge:** Includes a 10-hour online course and a two-day face-to-face lab.
- **EC-Council Network Defense Essentials Certification:** Serves as the final exam and builds on the previous certifications.

Students should add each earned credential to their LinkedIn account to showcase their progress and professional skills.
