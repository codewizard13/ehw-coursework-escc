# Week 12 Overview - Files, Streams, Persistence, and Program Testing

## Week 12: Files, Streams, Persistence, and Program Testing

**Due date:** Sunday, November 8, 2026 at 11:59 PM Central.

### Learning Objectives

By the end of this week, you should be able to explain and apply:

*   file streams
*   reading/writing text
*   state persistence
*   test plans
*   documenting test evidence

## Required Learning Before Graded Work

**Complete every reading and video listed below before the discussion, programming assignment, or quiz.** The programming work for this week is based only on concepts introduced in these resources and earlier weeks.

### Assigned Readings

### Learning targets

*   open/close file streams
*   write text to a file
*   read text from a file
*   check file-open success
*   design and document repeatable tests

### 1. C++ Institute assignment

**C++ Institute courses do not make file persistence the central focus here; use the required W3Schools/TutorialsPoint file lessons below as the primary instruction. Reuse only classes/functions already learned.**

### 2. Required W3Schools / Google reading

1.  **[W3Schools — C++ Files](https://www.w3schools.com/cpp/cpp_files.asp)**  
    Read the entire page. Type the `ofstream`/`ifstream` examples, create a real text file, then read it back.
2.  **[W3Schools — C++ Debugging (review)](https://www.w3schools.com/cpp/cpp_debugging.asp)**  
    Review compile/run/debug cycle before testing file-open and data cases.

### 3. Required TutorialsPoint reading

1.  **[TutorialsPoint — C++ Files and Streams](https://www.tutorialspoint.com/cplusplus/cpp_files_streams.htm)**  
    Study `fstream`, `ifstream`, `ofstream`, opening/closing, writing, and reading.
2.  **[TutorialsPoint — Basic Input/Output (stream review)](https://www.tutorialspoint.com/cplusplus/cpp_basic_input_output.htm)**  
    Review stream concepts so file streams feel like an extension of console streams.

### 4. Required video study

1.  **[Bro Code — User-defined functions (design review)](https://www.youtube.com/watch?v=vKTYM-DJDiw)[![](/images/play_overlay.png)](https://www.youtube.com/watch?v=vKTYM-DJDiw)**  
    Re-watch how to isolate a task in a function; use that skill to separate save/load/display responsibilities.
2.  **[Bro Code — Arrays explained (data review)](https://www.youtube.com/watch?v=QFrJQq6Iox8)[![](/images/play_overlay.png)](https://www.youtube.com/watch?v=QFrJQq6Iox8)**  
    Re-watch traversal if you store multiple records before writing them. File-stream syntax itself is taught in the assigned readings.

**How to study the videos:** Do not watch passively. Pause before the instructor runs each short example, predict the output, type the example yourself, compile it, then change one value or condition and run it again.
