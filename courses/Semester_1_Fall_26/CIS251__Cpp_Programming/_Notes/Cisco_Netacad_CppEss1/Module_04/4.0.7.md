# 🧩 4.0.7 An indexing operator for the stack

In order to show you the power of operator overloading, we’re going to show you an example implementation of a somewhat surprising operator. We’ll redefine the meaning of the **indexing operator**.

Yes, we know that it’s designed for arrays or array-like collections and it seems that the stack has nothing to do with it. But, from a certain point of view, a stack is an array – a very specific one, but still an array.

It’ll be very unorthodox indexing. We agree – its usability is highly debatable, but in our opinion it’ll work perfectly as a guinea pig in our operator’s lab.

We want the indexing to work in this odd way:

Stack\[0\] returns a reference to the element lying at the top of the stack

Stack\[-1\] returns a reference to the element lying below the top of the stack

etc, etc.

Note that this is **a reference, not a value**, as we want to use the operator inside _l-value_ expressions, e.g. as a left argument of the assignment operator.

An attempt to reach for a non-existent stack element will cause an exception to be thrown. It seems that the std::range\_error is the best candidate for this purpose.

OK. Let’s write a declaration:


```cpp
int& operator[](int index) throw(std::range_error);
```  

Note:

*   the function returns a value of type int& as the stack’s element type is int
*   the function has one argument – the index; we pass it by value as the array index doesn’t need to be a variable – it may be an expression too

Here’s the definition:

  

```cpp
int& Stack::operator[] (int index) throw(std::range_error) {
	if(index > 0 || index <= -SP)
		throw std::range_error("out of stack");
	return stackstore[SP + index - 1];
}
```

  

Note how we find the target element and how we calculate its position within the stack.

The newest version of the `main` function is in the editor:

```cpp
#include "mystack_06.h"
#include <iostream>

using namespace std;

int main(void) {
	int i = 2, j;
	Stack stk;
	stk << 1 << 2 * i;
	cout << stk[0] << endl << stk[-1] << endl;
	stk[0] = stk[-1] = 0;
	stk >> i >> j;
	cout << i << endl << j << endl;
	return 0;
}
```


The program produces the following output:

  

```
4
1
0
0
```
