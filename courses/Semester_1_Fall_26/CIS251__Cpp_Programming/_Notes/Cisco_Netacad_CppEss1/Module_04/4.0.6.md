# 🧩 4.0.6 What do we want to achieve?

Implementing overloaded operators as member functions is easy when you’re the “owner” of the class and you can modify its source code in any way. It may be impossible when the source code is unavailable. Of course, in many cases it may be possible to write your own subclass containing all the desired operators, but this may be inconvenient in some cases.

Fortunately, **you’re allowed to write operator functions outside any class** – using both kinds of operators is the same, and when you use an overloaded operator without knowing its implementation, you’re not able to guess which of the methods has been used.

In our case, a standalone operator function must have two arguments and the order of the arguments reflects the order of the operator’s arguments.

Be warned: not all operators may be overloaded in this way.

We’ll discuss both of these aspects soon.

Let's assume that our stack has returned to its pristine condition and doesn’t contain any operator functions. We won’t touch it. We’ll add all the required definitions to the main module.

The new, updated main function is in the editor:

```cpp
#include "mystack.h"
#include <iostream>

using namespace std;

Stack& operator<< (Stack &s, int v) throw(stack_overflow) {
	s.push(v);
	return s;
}

Stack& operator>>(Stack &s, int &v) throw(stack_empty) {
	v = s.pop();
	return s;
}

int main(void) {
	int i = 2, j;
	Stack stk;
	stk << 1 << 2 * i;
	stk >> j >> i;
	cout << j << endl << i << endl;
	return 0;
}
```
