# 🧩 4.0.4 Implementing the >> operator

Second, we’ll define the operator for the pop member function. Note that there’s one important difference between the previous operator and the current one.

**We’re not allowed (for obvious reasons) to store a value popped from the stack inside a literal or an expression**. We have to put it into a variable (or to be more precise, into an _l-value_).

On the other hand, a parameter passed by value isn’t able to transfer data in any other direction than from the outside into the function. This isn’t what we need.

But this is why we declare the function’s only argument as passed by reference.

The complete declaration is here:

```cpp
void operator >> (int &v)throw(stack_empty);
```

So now you should be able to write the function’s implementations without our help, but for the record, we give it here:

  

```cpp
void Stack::operator>> (int &v) throw(stack_empty) {
    v = pop();
}
```

Here’s the modified main function:

```cpp
#include "mystack_02.h"
#include <iostream>

using namespace std;

int main(void) {
    int i = 2;
    Stack stk;
    stk << 1;
    stk << 2 * i;
    stk << i;
    stk >> i; cout << i << endl;
    stk >> i; cout << i << endl;
    stk >> i; cout << i << endl;

    return 0;
}
```  

Try to use the “>>” illegally i.e. in conjunction with an expression or a literal. It shouldn’t work (in any case, we hope it won’t work).
