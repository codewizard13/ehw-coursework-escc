## Week 2 Programming Assignment — Data Types, Constants, Operators, Expressions, and Numeric Calculations

### Programming Task: Purchase Total Calculator

Write a console program that asks the user for a product name, quantity, and unit price. Store a tax rate in a `const double`. Calculate subtotal, tax amount, and final total. Display a clearly labeled receipt-style summary.

### Required C++ features

* [x] appropriate variables/data types;
* [x] one named constant for the tax rate;
* [x] `cin`/`cout`;
* [x] arithmetic operators and parentheses where appropriate;
* [x] at least one calculation that uses decimal arithmetic.

### Do not use yet

Do not use `if`, `switch`, loops, arrays, functions other than `main()`, classes, exceptions, or any library/API not assigned in Weeks 1–2.

### Required Process

1. [x] Write pseudocode for input → calculations → output.
2. [x] Manually calculate the expected subtotal/tax/total for at least three test cases before running the program.
3. [x] Compile incrementally and correct compiler errors.
4. [x] Compare actual results with your manual calculations.
