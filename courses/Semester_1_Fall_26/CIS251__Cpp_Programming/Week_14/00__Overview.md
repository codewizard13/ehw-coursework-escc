### 2. Required W3Schools / Google reading

1.  **[Google AI Studio Quickstart](https://ai.google.dev/gemini-api/docs/ai-studio-quickstart)**  
    Read the sections on creating/running a chat prompt and reviewing model responses. You are using the web interface; no Gemini API programming is required.
2.  **[Google — Prompt Design Strategies](https://ai.google.dev/gemini-api/docs/prompting-strategies)**  
    Study clear instructions, context, examples, constraints, and iterative refinement. Focus on prompts that explicitly limit suggestions to CIS 251 concepts.
3.  **[Google Skills — Introduction to Generative AI](https://www.skills.google/course_templates/536)**  
    Complete the introductory microlearning. Focus on what generative AI is, what it can/cannot reliably do, and responsible use.
4.  **[Google Skills — Introduction to Vertex AI Studio](https://www.skills.google/course_templates/552)**  
    Complete the introductory lessons/lab portions assigned by the instructor that explain prompt design and model interaction. This is conceptual reinforcement; the graded assignment uses Google AI Studio.
