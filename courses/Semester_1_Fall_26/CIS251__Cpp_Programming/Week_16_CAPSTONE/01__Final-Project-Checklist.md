# Final Project Checklist

## Before You Submit

*   Project compiles and runs from clean source.
*   All required C++ features are present for a reason, not merely added to satisfy a checklist.
*   Input validation and failure paths have been tested.
*   File data can be created/read/updated as required.
*   At least 10 documented test cases include expected and observed outcomes.
*   No API keys, passwords, tokens, or private data are submitted.
*   AI Studio prompts and verification notes are included.
*   You can explain each major function/class and demonstrate how the program meets requirements.
*   README and demonstration evidence are included.
