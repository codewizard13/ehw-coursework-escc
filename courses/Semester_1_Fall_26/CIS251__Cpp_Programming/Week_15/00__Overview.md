# Week 15 Overview - Capstone Preparation: Architecture, Integration, Documentation, and Demonstration

## Week 15: Capstone Preparation: Architecture, Integration, Documentation, and Demonstration

**Due date:** Sunday, December 6, 2026 at 11:59 PM Central.

### Learning Objectives

By the end of this week, you should be able to explain and apply:

*   requirements
*   modular architecture
*   OOP integration
*   file persistence
*   testing
*   AI-assisted review
*   final demonstration

## Required Learning Before Graded Work

**Complete every reading and video listed below before the discussion, programming assignment, or quiz.** The programming work for this week is based only on concepts introduced in these resources and earlier weeks.

### Assigned Readings

### Learning targets

*   translate a problem into requirements
*   design a modular C++ solution
*   plan data/classes/functions/persistence
*   construct a comprehensive test plan
*   prepare a prototype without introducing new technology

### 1. C++ Institute assignment

**No new C++ feature is introduced. This week is structured synthesis of previously learned features before the final project.**

### 2. Required W3Schools / Google reading

1.  **[W3Schools — Functions (capstone review)](https://www.w3schools.com/cpp/cpp_functions.asp)**  
    Review decomposition and identify which final-project responsibilities belong in separate functions.
2.  **[W3Schools — Classes/Objects (capstone review)](https://www.w3schools.com/cpp/cpp_classes.asp)**  
    Review class structure and identify the primary class(es) in your project.
3.  **[W3Schools — Files (capstone review)](https://www.w3schools.com/cpp/cpp_files.asp)**  
    Review save/load syntax before planning persistence.
4.  **[W3Schools — Debugging (capstone review)](https://www.w3schools.com/cpp/cpp_debugging.asp)**  
    Review the debugging process and use it to define a test plan.
5.  **[Google — Prompt Design Strategies (review)](https://ai.google.dev/gemini-api/docs/prompting-strategies)**  
    Review how to constrain AI Studio to already-taught concepts when planning tests or reviewing code.

### 3. Required TutorialsPoint reading

1.  **[TutorialsPoint — Classes/Objects (review)](https://www.tutorialspoint.com/cplusplus/cpp_classes_objects.htm)**  
    Use this as a second explanation while drafting your class design.
2.  **[TutorialsPoint — Files/Streams (review)](https://www.tutorialspoint.com/cplusplus/cpp_files_streams.htm)**  
    Use this as a second explanation while drafting persistence behavior.

### 4. Required video study
