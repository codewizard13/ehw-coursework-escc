# C++ Introduction

## What is C++?

- is a cross-platform language that can be used to create high-performance applications.

- was developed by Bjarne Stroustrup, as an extension to the [C language](/c/index.php).

- gives programmers a high level of control over system resources and memory.

- has evolved over the years, with major versions including C++11, C++14, C++17, C++20, C++23, and C++26.

- - -

## Why Use C++

- is one of the world's most popular programming languages.

- can be found in today's operating systems, Graphical User Interfaces, and embedded systems.

- is an object-oriented programming language which gives a clear structure to programs and allows code to be reused, lowering development costs.

- is portable and can be used to develop applications that can be adapted to multiple platforms.

- is fun and easy to learn!

- As C++ is close to [C](/c/index.php), [C#](/cs/index.php) and [Java](/java/default.asp), it makes it easy for programmers to switch to C++ or vice versa.

- - -

## Difference between C and C++

- was developed as an extension of [C](/c/index.php), and both languages have almost the same syntax.

- The main difference between C and C++ is that **C++ supports classes and objects**, while C does not.
