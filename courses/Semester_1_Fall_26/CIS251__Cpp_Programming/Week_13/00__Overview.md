# Week 13 Overview - C++ Integration: STL Containers, Algorithms, and Design Refactoring

## Week 13: C++ Integration: STL Containers, Algorithms, and Design Refactoring

**Due date:** Sunday, November 15, 2026 at 11:59 PM Central.

### Learning Objectives

By the end of this week, you should be able to explain and apply:

*   std::vector
*   basic STL algorithms
*   iterators/range loops
*   refactoring
*   complexity awareness

## Required Learning Before Graded Work

**Complete every reading and video listed below before the discussion, programming assignment, or quiz.** The programming work for this week is based only on concepts introduced in these resources and earlier weeks.

### Assigned Readings

### Learning targets

*   create/use `std::vector`
*   explain vector versus array
*   traverse a container
*   apply one standard algorithm
*   refactor without changing required behavior

### 1. C++ Institute assignment

**C++ Essentials 1 — Module 2 introduces vectors. This week extends that prior introduction with the specific W3Schools/TutorialsPoint vector, iterator, and algorithm pages below.**

### 2. Required W3Schools / Google reading

1.  **[W3Schools — C++ Vectors](https://www.w3schools.com/cpp/cpp_vectors.asp)**  
    Study declaration, adding/removing elements, size, and element access.
2.  **[W3Schools — C++ Iterators](https://www.w3schools.com/cpp/cpp_iterators.asp)**  
    Study iterator purpose and traversal syntax; compare with index/range-based loops.
3.  **[W3Schools — C++ Algorithms](https://www.w3schools.com/cpp/cpp_algorithms.asp)**  
    Study only the algorithms demonstrated in the required page and guided practice, especially sorting/searching examples relevant to the assignment.
4.  **[W3Schools — Arrays (comparison review)](https://www.w3schools.com/cpp/cpp_arrays.asp)**  
    Review fixed-size arrays so you can explain why a vector may be a better fit for variable-size data.

### 3. Required TutorialsPoint reading

1.  **[TutorialsPoint — C++ Standard Library vector](https://www.tutorialspoint.com/cpp_standard_library/vector.htm)**  
    Study common `vector` operations used in the guided examples.
2.  **[TutorialsPoint — C++ STL Tutorial](https://www.tutorialspoint.com/cplusplus/cpp_stl_tutorial.htm)**  
    Read the overview of containers, algorithms, and iterators; do not attempt template metaprogramming or advanced containers.
