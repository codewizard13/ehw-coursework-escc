## Week 3 Programming Assignment - Decision Structures and Boolean Logic

**Preparation requirement:** Complete the Week 3 readings, videos,[C++ Institute practice,](https://www.netacad.com/courses/c-plus-plus-essentials-1?courseLang=en-US&instance_id=4e9bfae1-812a-47b1-9052-43a5f27db6ff "Link")and guided examples before starting. This assignment intentionally requires only concepts taught in those materials.

### Programming Task

Shipping Charge Decision Program: ask for an order amount and shipping option, use if/else and/or switch to select the correct charge from a supplied decision table, and print the final amount. Include boundary tests for every branch.

### Required Process

1.  Write a short algorithm/pseudocode plan using only this week's and prior weeks' concepts.
2.  Implement and compile incrementally.
3.  Use meaningful variable/function/class names appropriate to the concepts already studied.
4.  Test normal, boundary, and invalid inputs when applicable.
5.  Correct compiler warnings/errors and verify output against your own expected results.

### Submit

- Your `.cpp` source file(s) (and header files only if your design uses them).
- A short test table with at least five test cases: input, expected result, actual result, pass/fail.
- Screenshot or text evidence showing the program compiled and ran.
- AI Assistance Log if AI was used. AI may explain/review concepts already taught, but it may not introduce unassigned libraries, frameworks, or C++ features.
