### CIS 251 - C++ Programming:
# Week 9 Overview - Inheritance, Composition, and Polymorphic Design

**Due date:** Sunday, October 18, 2026 at 11:59 PM Central.

### Learning Objectives

By the end of this week, you should be able to explain and apply:

*   inheritance
*   is-a vs has-a
*   base/derived classes
*   virtual behavior concepts
*   composition

## Required Learning Before Graded Work

**Complete every reading and video listed below before the discussion, programming assignment, or quiz.** The programming work for this week is based only on concepts introduced in these resources and earlier weeks.

### Assigned Readings

### Learning targets

*   identify base and derived classes
*   implement simple inheritance
*   distinguish inheritance from composition
*   explain overriding and virtual dispatch
*   preserve encapsulation in a hierarchy

### 1\. C++ Institute assignment

**C++ Essentials 2 — Module 2: class hierarchies, inheritance/type compatibility, polymorphism/virtual methods, and objects as parameters. Focus on single inheritance and basic virtual behavior.**

### 2\. Required W3Schools / Google reading

1.  **[W3Schools — C++ Inheritance](https://www.w3schools.com/cpp/cpp_inheritance.asp)**  
    Study base/derived class syntax and inherited members.
2.  **[W3Schools — Inheritance Access](https://www.w3schools.com/cpp/cpp_inheritance_access.asp)**  
    Study the effect of access levels; graded work emphasizes straightforward public inheritance.
3.  **[W3Schools — C++ Polymorphism](https://www.w3schools.com/cpp/cpp_polymorphism.asp)**  
    Study method overriding and the conceptual purpose of polymorphism.
4.  **[W3Schools — Virtual Functions](https://www.w3schools.com/cpp/cpp_virtual_functions.asp)**  
    Study `virtual`, overriding, and base-pointer/reference behavior at the introductory level.

### 3\. Required TutorialsPoint reading

1.  **[TutorialsPoint — C++ Inheritance](https://www.tutorialspoint.com/cplusplus/cpp_inheritance.htm)**  
    Study base and derived classes and simple inheritance syntax.
2.  **[TutorialsPoint — C++ Polymorphism](https://www.tutorialspoint.com/cplusplus/cpp_polymorphism.htm)**  
    Study compile-time versus run-time terminology; focus on virtual functions and overriding for this course.

### Assigned Videos

### 4\. Required video study
