# CIS 251 - C++ Programming:  <br> Week 6 Overview - Arrays, Strings, and Sequential Data Processing

## Week 6: Arrays, Strings, and Sequential Data Processing

**Due date:** Sunday, September 27, 2026 at 11:59 PM Central.

### Learning Objectives

By the end of this week, you should be able to explain and apply:

*   fixed-size arrays
*   std::string
*   iteration over collections
*   searching/counting
*   bounds awareness

## Required Learning Before Graded Work

**Complete every reading and video listed below before the discussion, programming assignment, or quiz.** The programming work for this week is based only on concepts introduced in these resources and earlier weeks.

### Assigned Readings

### Learning targets

*   declare and initialize arrays
*   use zero-based indexes
*   traverse arrays with loops
*   combine arrays with functions/decisions
*   perform basic `string` operations

### 1\. C++ Institute assignment

**C++ Essentials 1 — Module 2: vectors/arrays (focus on arrays); Module 4 string manipulation basics.**

### 2\. Required W3Schools / Google reading

1.  **[W3Schools — C++ Arrays](https://www.w3schools.com/cpp/cpp_arrays.asp)**  
    Study declaration, initialization, indexes, changing elements, size, and iteration.
2.  **[W3Schools — Loop Through an Array](https://www.w3schools.com/cpp/cpp_arrays_loop.asp)**  
    Practice index-based and range-based iteration.
3.  **[W3Schools — C++ Strings](https://www.w3schools.com/cpp/cpp_strings.asp)**  
    Study `string` declaration, concatenation, input considerations, and length.
4.  **[W3Schools — Access Strings](https://www.w3schools.com/cpp/cpp_strings_access.asp)**  
    Study indexing and bounds awareness.
5.  **[W3Schools — String Methods](https://www.w3schools.com/cpp/cpp_strings_methods.asp)**  
    Study only the methods demonstrated on the page and used in guided practice.

### 3\. Required TutorialsPoint reading

1.  **[TutorialsPoint — C++ Arrays](https://www.tutorialspoint.com/cplusplus/cpp_arrays.htm)**  
    Study one-dimensional arrays, initialization, and element access.
2.  **[TutorialsPoint — C++ Strings](https://www.tutorialspoint.com/cplusplus/cpp_strings.htm)**  
    Study the `std::string` examples and basic operations.
