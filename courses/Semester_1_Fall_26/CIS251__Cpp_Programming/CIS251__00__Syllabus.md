## Course Description

This course is an introduction to the C++ programming language, including object-oriented programming. Topics include problem solving and design, control structures, objects and events, user interface construction, and program testing.

## Learning Outcomes

Students will be able to:

- Develop programs using C++ syntax and structure.
- Apply control structures in problem solving.
- Create and manipulate objects.
- Implement user interfaces in C++.

## Assessment

**Course overview:** Object-oriented programming in C++ using Cisco NetAcad C++ Essentials 1 and 2.

**Duration:** August 18 - December 6, 2025

## Weekly Expectations

Each instructional week includes an overview, readings/videos, a graded discussion, a programming assignment, and a quiz. Students should budget consistent time for reading, coding, testing, revision, and reflection.

## AI Use Standard

Google AI Studio and other permitted AI tools may be used to support learning, planning, debugging, testing, documentation, and review. Students remain responsible for understanding every submitted line of code, verifying generated suggestions, protecting private data and credentials, and disclosing substantive AI assistance. Submitting AI-generated work that the student cannot explain does not demonstrate mastery.

## Final Project

The final examination is a cumulative C++ programming project. Students will use Google AI Studio as a documented software-engineering assistant while independently designing, implementing, testing, debugging, and demonstrating the C++ application.
