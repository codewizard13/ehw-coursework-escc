# CIS 251 - C++ Programming:  <br> Week 4 Overview - Loops, Repetition, and Algorithmic Tracing

**Due date:** Sunday, September 13, 2026 at 11:59 PM Central.

### Learning Objectives

By the end of this week, you should be able to explain and apply:

*   while loops
*   do-while loops
*   for loops
*   sentinel and counter control
*   nested loops

## Required Learning Before Graded Work

**Complete every reading and video listed below before the discussion, programming assignment, or quiz.** The programming work for this week is based only on concepts introduced in these resources and earlier weeks.

### Assigned Readings

### Learning targets

*   choose between `for`, `while`, and `do...while`
*   trace loop execution
*   use counters and accumulators
*   avoid infinite loops
*   combine loops with previously learned decisions

### 1\. C++ Institute assignment

**C++ Essentials 1 — Module 2: loops and controlling loop execution.**

### 2\. Required W3Schools / Google reading

1.  **[W3Schools — C++ While LoopLinks to an external site.](https://www.w3schools.com/cpp/cpp_while_loop.asp)**  
    Study condition-controlled repetition and the infinite-loop warning.
2.  **[W3Schools — C++ Do/While LoopLinks to an external site.](https://www.w3schools.com/cpp/cpp_do_while_loop.asp)**  
    Study why the loop body executes at least once.
3.  **[W3Schools — C++ For LoopLinks to an external site.](https://www.w3schools.com/cpp/cpp_for_loop.asp)**  
    Study initialization, condition, update, counters, and accumulation patterns.
4.  **[W3Schools — C++ Nested LoopsLinks to an external site.](https://www.w3schools.com/cpp/cpp_nested_loops.asp)**  
    Read the examples; nested loops are for recognition/practice, not required in the graded assignment.
5.  **[W3Schools — C++ Break and ContinueLinks to an external site.](https://www.w3schools.com/cpp/cpp_break.asp)**  
    Study how `break` and `continue` alter loop execution.

### 3\. Required TutorialsPoint reading

1.  **[TutorialsPoint — C++ Loop TypesLinks to an external site.](https://www.tutorialspoint.com/cplusplus/cpp_loop_types.htm)**  
    Read `while`, `for`, and `do...while`, then compare when each is appropriate.
