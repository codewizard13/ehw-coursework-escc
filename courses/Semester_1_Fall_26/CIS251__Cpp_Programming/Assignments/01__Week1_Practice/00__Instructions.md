# 🧪 Required Practice Exercises

### ✔️ Exercise 1 — Greeting Program

Print three lines of text using `cout`.

### ✔️ Exercise 2 — Variables

Create variables for your name, age, and GPA. Print them.

### ✔️ Exercise 3 — Calculator

Ask the user for two numbers. Compute:

*   Addition
    
*   Subtraction
    
*   Multiplication
    
*   Division
    

### ✔️ Exercise 4 — Escape Sequence Table

Use escape sequences to create a table:

Code

```
Name      Age
Alice     20
Bob       22
```
