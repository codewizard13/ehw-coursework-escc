# 📘 Course Syllabus: CIS 260 — Network Security and Risk Management

## Course Overview

This course introduces network security principles and the practices used to protect digital systems and information. Students study risk assessment, security controls, common cyber threats, and the strategies organizations use to reduce risk and maintain resilient IT operations.

**Real-world application:** network security is essential for protecting businesses, personal data, infrastructure, cloud environments, and online services from cyber threats.

### Learning Outcomes

- Identify common security threats and vulnerabilities.
- Explain how access control, encryption, and network protections reduce risk.
- Describe the role of risk management in organizational security.
- Evaluate basic security policies and operational safeguards.
- Apply foundational security concepts to network environments.

### Topics Covered

- Security principles and foundational concepts
- Network threats and vulnerabilities
- Risk assessment and controls
- Access control, authentication, and authorization
- Firewalls, intrusion prevention, and monitoring
- Incident response basics
- Security policy and compliance considerations

### Assessment

- Security concept exercises
- Case analysis and risk scenarios
- Written assignments
- Quizzes and practical project work
