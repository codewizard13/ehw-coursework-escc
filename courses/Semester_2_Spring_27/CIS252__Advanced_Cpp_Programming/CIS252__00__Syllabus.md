# 📘 Course Syllabus: CIS 252 — Advanced C++ Programming

## Course Overview

This course builds on introductory programming and explores more advanced C++ concepts, including modular design, classes, memory management, data structures, and algorithmic problem solving. Students gain practical experience writing efficient and maintainable software.

**Real-world application:** advanced C++ is important for game engines, simulation systems, high-performance applications, robotics, and embedded technology.

### Learning Outcomes

- Apply advanced C++ language features in software design.
- Use classes, inheritance, and abstraction effectively.
- Write programs that manage memory and data structures efficiently.
- Implement common algorithms and solve complex coding problems.
- Debug and improve code quality in larger applications.

### Topics Covered

- Advanced control flow and functions
- Object-oriented programming in depth
- Memory management and pointers
- Data structures and algorithm design
- File I/O and modular programming
- Debugging and testing strategies
- Code organization and maintainability

### Assessment

- Programming assignments
- Debugging exercises
- Projects and code reviews
- Quizzes and practical exams

### Materials

- C++ compiler or IDE
- Code editor and project tools
- Course exercises and sample programs
- Reference notes and problem sets
