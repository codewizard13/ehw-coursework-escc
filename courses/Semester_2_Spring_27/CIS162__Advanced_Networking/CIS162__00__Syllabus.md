# 📘 Course Syllabus: CIS 162 — Advanced Networking

## Course Overview

This course expands on networking fundamentals and emphasizes advanced concepts, configuration, and troubleshooting. Students investigate internetworking, routing, switching, network services, and how enterprise networks are designed and maintained.

**Real-world application:** advanced networking knowledge supports enterprise environments, cybersecurity operations, cloud connectivity, and scalable IT infrastructure.

### Learning Outcomes

- Explain advanced network design and communication concepts.
- Configure and diagnose common networking components.
- Understand routing, switching, and connectivity between networks.
- Apply troubleshooting strategies to connectivity and performance issues.
- Describe how networks support enterprise and cloud services.

### Topics Covered

- Routing and switching fundamentals
- IP addressing and subnetting review
- Network performance and troubleshooting
- WAN and LAN concepts
- Network services and protocols
- Enterprise network design basics
- Security considerations in network systems

### Assessment

- Hands-on configuration labs
- Diagnostic exercises
- Network design scenarios
- Quizzes and practical evaluations

### Materials

- Networking lab tools
- Simulation platforms
- Course notes and diagrams
- Instructor-provided lab tasks
