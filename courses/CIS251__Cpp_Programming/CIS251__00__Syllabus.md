# 📘 Course Syllabus: CIS 251 — C++ Programming

## Course Overview

This course introduces the C++ programming language and the concepts of structured, object-oriented, and systems-level programming. Students learn how to write programs that solve problems efficiently while exploring variables, control flow, functions, classes, and memory concepts.

**Real-world application:** C++ is used in software engineering, game development, embedded systems, robotics, high-performance computing, and system-level tools.

### Learning Outcomes

- Write C++ programs using variables, operators, and control structures.
- Use functions, arrays, and data handling techniques to solve problems.
- Understand object-oriented concepts such as classes and methods.
- Debug common logic and syntax errors in C++ programs.
- Apply programming principles to practical software tasks.

### Topics Covered

- C++ syntax and program structure
- Input/output and data types
- Decisions and loops
- Functions and scope
- Arrays and strings
- Pointers and memory basics
- Object-oriented programming concepts
- File handling and basic algorithms

### Assessment

- Programming exercises
- Quizzes and short practical checks
- Lab assignments
- Midterm and final coding projects

### Materials

- Code editor and terminal
- Textbook or course examples
- Practice exercises and assignments
